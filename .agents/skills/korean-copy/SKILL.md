# 한국어 문구

이 스킬이 COPY-01 의 정본이다. 대상은 `README.ko.md`·`CHANGELOG.ko.md` 다. 에이전트 문서(`AGENTS.md`, `.agents/`)는 한다체로 짧게 쓴다.

## 규칙

- **어조**: 사용자 문서는 합니다체. 한 문서 안에서 섞지 않는다.
- **영어판을 옮기지 말고 한국어로 다시 쓴다**: 내용은 영어판과 같게, 문장은 한국어 순서로. 영어 어순을 따라간 티가 나는 표현을 피한다.

  | 피할 것                         | 쓸 것                       |
  | ------------------------------- | --------------------------- |
  | `X 에 대한 지원을 추가했습니다` | `X 를 지원합니다`           |
  | `~하는 것이 가능합니다`         | `~할 수 있습니다`           |
  | `~를 제공합니다`(도구가 주어)   | `~합니다`, `~가 들어 있습니다` |
  | `성공적으로 ~되었습니다`        | `~했습니다`                 |

- **이름은 하는 일 그대로 짓는다**: 명령·옵션·절 제목을 비유로 짓지 않는다. `audio loop` 는 "반복 재생용 파일 만들기"다.
- **CHANGELOG 의 절 제목**: 영어판 `Unreleased` 는 한국어판 `미출시`. 버전 절(`## 0.2.0`)은 두 판이 같다.
